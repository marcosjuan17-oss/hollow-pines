# Hollow Pines

A first-person horror game that runs in the browser. Your flashlight is dying: follow the trail to the cabin, grab the green battery cells, and don't let it go dark.

Play: https://marcosjuan17-oss.github.io/hollow-pines

On a phone, open the link and use **Add to home screen** to install it as an app.

Built with three.js. 3D models made in Blender.
